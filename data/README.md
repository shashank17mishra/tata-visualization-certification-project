Place your datasets in this `data/` directory.

Guidelines:
- Small CSV files can be committed directly (e.g., < 5MB).
- For large datasets, do NOT commit them to the repository. Instead:
  - Add them to cloud storage (Google Drive, S3, etc.) and provide download links here.
  - Or use Git LFS for versioning large files.

Example:
- data/my_dataset.csv  # a small sample dataset used by the notebooks

If you add large files, update `.gitignore` accordingly and include download instructions below.
